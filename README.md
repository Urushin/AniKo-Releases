## Pourquoi AniKo

| | |
|---|---|
| 📚 **Un lecteur soigné** | PDF, CBZ, EPUB non protégé, images. Reprise automatique, lecture verticale ou page à page. |
| 🎬 **Un lecteur vidéo complet** | Vos fichiers et vos serveurs, avec reprise et sous-titres. |
| 📈 **Un suivi fiable** | Synchronisation AniList et MyAnimeList, calendrier des sorties. |
| 🖥️ **Vos serveurs** | Komga, Kavita, Suwayomi, compatibles Aniyomi. |
| 🧩 **Des modules à vous** | Ajoutez vos propres modules, activés un par un, après votre accord. |
| 🔒 **Privé par défaut** | Aucun compte AniKo. Tout reste sur votre appareil. |

> AniKo n'héberge, ne diffuse et ne recommande aucun contenu. Vous utilisez vos fichiers, vos serveurs et vos modules, sous votre responsabilité.

## Installer

Il vous faut [AltStore](https://altstore.io) ou [SideStore](https://sidestore.io) déjà installé sur votre iPhone.

1. Sur l'iPhone, touchez un des boutons **Ajouter à…** en haut de cette page.
2. Ou ajoutez la source à la main : *Sources* → **+** → collez

   ```
   https://mangaanimezone.pages.dev/altstore/apps.json
   ```
3. Ouvrez **AniKo** dans la source, touchez **Gratuit** puis **Installer**.
4. Si l'icône n'apparaît pas : *Réglages → Général → VPN et gestion de l'appareil* → faites confiance à votre profil.

Ou téléchargez l'**IPA** directement dans [les releases](https://github.com/Urushin/AniKo-Releases/releases/latest).

> Avec un compte Apple gratuit, l'app doit être renouvelée tous les 7 jours. AltStore et SideStore le font automatiquement.

## Cette édition

- Gratuite, sans annonces ni limites.
- Pas d'achat intégré (impossible hors App Store), pas de synchronisation iCloud.
- Le widget peut rester vide avec un compte gratuit.

## Vérifier votre téléchargement

L'empreinte SHA-256 de chaque IPA est dans les notes de la release.

```bash
shasum -a 256 AniKo-sideload.ipa
```
